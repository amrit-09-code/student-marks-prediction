# 🎓 Student Marks Prediction

A Machine Learning + Django web app that predicts a student's marks based on study hours, previous scores, attendance, and other factors.

## ✨ Features
- Predict student marks using ML model
- User-friendly Django web interface
- Data visualization with graphs (output1, output2)
- Easy to run locally

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Django
- **ML Libraries:** Scikit-learn, Pandas, NumPy, Matplotlib
- **Frontend:** HTML, CSS, Bootstrap
- **Database:** SQLite3
